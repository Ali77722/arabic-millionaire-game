# من سيربح المليون 🇮🇶

لعبة مسابقات جماعية عربية RTL تعمل مباشرة في المتصفح، ومهيأة لـ GitHub Pages والعمل دون API خارجي.

## المزايا

- فرق متعددة من 2 إلى 6 فرق مع اسم وأيقونة ولون مستقل.
- 760 سؤالًا مضمّنًا، موزعة على 19 مجالًا و4 مستويات صعوبة.
- منع تكرار السؤال داخل الجولة واختيار عشوائي مع تدرج الصعوبة.
- سلم جوائز قياسي يصل إلى 1,000,000 مع خيار مختصر أو مخصص.
- 50:50، سؤال الجمهور، الاتصال بصديق، وتبديل السؤال.
- مؤقت 30/45/60 ثانية أو بدون مؤقت.
- أصوات وموسيقى مولدة محليًا عبر Web Audio API.
- حفظ واستكمال اللعبة عبر LocalStorage مع حفظ الوقت المتبقي للسؤال.
- إحصائيات وسجل نتائج محلي.
- استيراد JSON مع فحص بنية الأسئلة.
- Responsive للكمبيوتر والهاتف والتابلت.
- Service Worker لتخزين الملفات الأساسية والعمل دون اتصال بعد أول تحميل.

## التشغيل

افتح index.html في متصفح حديث. ولتجربة Service Worker وOffline استخدم خادمًا محليًا أو GitHub Pages.

## GitHub Pages

من Settings ثم Pages اختر النشر من فرع main ومجلد الجذر (/).

## قاعدة الأسئلة

المتصفح يجمع الأجزاء السبعة ثم يفك ضغطها محليًا باستخدام DecompressionStream ويحوّلها إلى مصفوفة أسئلة. لكل سؤال الحقول:
id, question, options, answer, category, difficulty, prize, explanation.

يمكن استيراد JSON من الإعدادات. يجب أن تكون القاعدة مصفوفة وكل سؤال يحتوي على 4 خيارات فريدة وإجابة واحدة صحيحة.

## تعديل الأسئلة

استخدم نفس البنية السابقة. محرك اللعبة لا يحتاج تعديلًا عند تغيير محتوى الأسئلة ما دامت البنية صحيحة.

## الجوائز والإعدادات

يمكن تعديل سلم الجوائز والمؤقت والصعوبة والصوت والموسيقى والوضع الليلي ووسائل المساعدة من الإعدادات، وتحفظ التغييرات محليًا.
